# Renaissance AI Coach — Full App Build

## Business Context
Personalised AI life coach app — daily tracker evolves into an intelligent coach that helps the user stay fit, make money, and grow skills. Built on the existing Renaissance codebase (React 19, Vite 8, TypeScript 6, Tailwind v4, Supabase, Framer Motion, recharts).

**User profile:** 6ft, 73kg. Sits at a desk all day. Core goal: "make money while staying fit."

## Constraints
- **Zero paid services.** Free Supabase tier only. No OpenAI, no external APIs.
- **AI coach is a local rules engine** — no ML, no external LLM calls.
- **Existing pages (Dashboard, Habits, Gym, Health, Leads, Analytics, Settings) remain untouched** except for the bug fixes and one Dashboard addition.

## Design Principles
- **One unified Body tab** replaces separate Gym + Health pages, adding Meals + Work tracking as sub-tabs.
- **Coach is the intelligence layer** — analyses tracked data and surfaces insights, no user input needed.
- **Career is a skill-building system** — prebuilt skill trees you level up through, not a live job board.
- **Everything is optional** — the app works as before if you ignore the new features.

## Navigation (7 items)
**Bottom nav:** Today | Habits | **Body** | **Coach** | **Career** | Leads | Settings

Settings moves from bottom nav to a gear icon accessible from each page's header.

## Pages & Routes

### `/body` — Unified Health, Fitness & Nutrition
Three sub-tabs using pill toggle (same pattern as Leads tabs):

**Gym** (existing) — untouched, just moved into sub-tab
**Health** (existing) — untouched, moved into sub-tab
**Meals** (NEW) — Quick-add meal logging with preset buttons (breakfast/lunch/dinner/snack). Shows daily calorie ring + protein bar at top.

**Work** (NEW) — Sitting time tracker with start/stop, break counter, break reminders, desk exercise suggestions (5 exercises: neck rolls, shoulder shrugs, seated twists, leg raises, wrist stretches).

### `/coach` — AI Coach Feed
Smart card feed generated by the rules engine. Card types in priority order:
1. **Priority Alert** — urgent health/sitting/streak issue
2. **Streak Saver** — about to lose a streak
3. **Meal Insight** — macro imbalance detected
4. **Work Pattern** — sitting time pattern detected
5. **Career Tip** — skill tree progress insight
6. **Skill Nudge** — learning gap detected
7. **Weekly Wrap** — end of week summary

Max 5 cards shown. Cards are dismissable. Stale cards auto-clear.

### `/career` — Wealth & Growth Dashboard
Three sections:
1. **Skill Trees** — Prebuilt skill paths (Sales, Coding, Content Creation, Trades, Digital Marketing). Each has 5 levels with concrete milestones. Log practice → earn XP → level up.
2. **Income Tracker** — Manual income logging, monthly total, trend, goal bar.
3. **Daily Learning Timer** — Same pattern as focus timer, branded for career skills. Logs to `skill_sessions`.

### Dashboard Update
Adds a "Coach Says" card below the existing stats — shows the top priority coach insight. Taps → navigates to `/coach`.

## New Hooks
- `useCoach.ts` — Rules engine. No API calls. Analyzes today's data vs goals, recent trends, streaks, gaps. Returns ordered array of coach cards.
- `useCareer.ts` — Fetches skill_trees, skill_progress, skill_sessions, income_logs.
- `useWork.ts` — Manages work session state (start/stop/pause), break tracking, sitting time calculation.

## Data Layer — New Tables

All on existing Supabase project, free tier:

```sql
meal_logs (id uuid PK, user_id uuid FK, date date, meal_type text,
  food_name text, calories int, protein_g numeric, created_at timestamptz)

skill_trees (id uuid PK, name text, category text, description text,
  levels jsonb) -- SEEDED data

skill_progress (id uuid PK, user_id uuid FK, skill_id uuid FK,
  current_level int, xp int, started_at timestamptz, completed_at timestamptz)

skill_sessions (id uuid PK, user_id uuid FK, skill_id uuid FK,
  date date, duration_min int, notes text)

income_logs (id uuid PK, user_id uuid FK, date date,
  amount numeric, source text, notes text)

work_sessions (id uuid PK, user_id uuid FK, date date,
  start_time time, end_time time, total_minutes int, breaks_taken int)

break_logs (id uuid PK, user_id uuid FK, date date,
  time time, duration_min int, break_type text)
```
